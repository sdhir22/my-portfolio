## Overview

Maple Buy is a Flutter-based mobile application that makes it easy for Canadians to discover domestically-made alternatives to foreign grocery products. Users can search by product or browse categorized listings to find Canadian-made options, complete with real-time reviews and community-contributed product data.

## Key Features

- **Product Discovery**: Search and browse Canadian-made grocery alternatives through an intuitive category-based listing interface.
- **Scalable Navigation**: Built with GoRouter for structured multi-screen routing, cleanly separating UI from route logic for maintainability.
- **Real-Time Reviews**: Integrated Firebase Firestore and Authentication to manage product listings, user-generated content, and live community reviews.
- **Async Data Handling**: Connected to a third-party Fast Foods API for grocery product data, with asynchronous data handling for smooth, non-blocking UI updates.

## Technologies Used

- **Flutter & Dart**: Cross-platform mobile UI framework for iOS and Android.
- **Firebase (Firestore & Auth)**: Backend for product listings, user accounts, and real-time reviews.
- **GoRouter**: Declarative routing for scalable multi-screen navigation.
- **Fast Foods API**: Third-party grocery product data source.
