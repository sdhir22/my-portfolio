## Overview

NutriPlan is an AI-powered meal planning web application that takes the guesswork out of eating well. Users input their dietary restrictions and weekly budget, and NutriPlan returns a personalized meal plan complete with step-by-step recipes and a consolidated grocery shopping list.

## Key Features

- **Personalized Meal Planning**: Generates a full week of meals tailored to the user's dietary restrictions and budget constraints.
- **Step-by-Step Recipes**: Each meal comes with detailed recipe instructions powered by the Spoonacular API.
- **Smart Grocery Lists**: Automatically compiles a shopping list from the weekly meal plan, grouped and optimized for the user's budget.
- **AI-Assisted Development**: Built with AI tooling throughout the development workflow to accelerate feature iteration and refine UI/UX design.

## Technologies Used

- **Next.js & Vercel**: For fast, server-rendered frontend and seamless deployment.
- **Spoonacular API**: For fetching personalized meal recommendations and detailed recipe data.
- **Cursor & Vercel AI SDK**: AI-assisted development tooling to accelerate feature development.

## Status

NutriPlan is currently in active development.
